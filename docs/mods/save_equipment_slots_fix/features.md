# Save Equipment Slots (Fix) · 功能说明

> 面向玩家的功能与用法（不含安装/部署，安装方式见工坊页面）。

「装备槽记忆」：给每件装备（可选扩展到食物、治疗品）记住它"该待在哪个槽位"，
下次槽位空了，同类物品自动回到原位。修复了原版**重上游戏、上下洞穴后记忆丢失**的问题，
并让槽位图标（含皮肤）稳定显示。

## 1. 它解决什么问题

| 场景 | 原版 | 本修复版 |
|---|---|---|
| 下洞穴再回地表 | 记忆丢失，要重新拖一遍 | 保留 |
| 重登 / 重启游戏 | 世界存档在就保留 | 保留（双保险） |
| 纯客户端连服务器后重登 | 记忆丢失 | 保留（存在你本机） |
| 槽位图标（含皮肤）重登后 | 方块 / 丢失 | 正常显示 |
| 换电脑 | — | 不跟随（存在本机） |

## 2. 怎么用

1. **自动记忆**：把要记住的物品放进装备槽/指定槽位，它就会被记住；
2. **自动回位**：该槽位空着时，同类物品（新捡的、背包里的）会自动回到那个槽位；
3. **暂停/恢复记忆**：默认 **Ctrl + V**（可在配置里改成 Ctrl + 其它字母，或设为「无」）；
   暂停时屏幕会有一行状态提示；
4. **清除某格记忆**：槽位上方会显示已记忆物品的小图标，**点击图标**即清除；
5. **配置项**（游戏内「Mods → 配置」）：

   | 配置 | 说明 |
   |---|---|
   | 应用类型 | 只记装备 / 装备+食物 / 装备+治疗 / 三者都记 / 全部物品 |
   | 显示槽位图标 | 是否在槽位上方显示小图标 |
   | 图标不透明度 / 缩放 / 垂直偏移 | 微调小图标外观 |
   | 暂停保存快捷键 | Ctrl + 字母（默认 V），或「无」 |
   | 初始开关状态 | 进游戏时记忆功能默认开 / 关 |
   | 暂停时禁用点击 | 记忆暂停后是否也禁用"点图标清除" |
   | 允许装备腾位 | 背包满时允许"先装备占位物品"给新物品腾地方 |
   | 保留已存槽位 | 是否把空槽位留给被记住的物品（从不 / 有空位时 / 总是） |

## 3. 和其它 mod 的关系

- **请禁用原版** Save Equipment Slots（dani 版），两者同时启用会重复处理物品移动逻辑；
- 与"漫漫长路"这类会移动/移除装备的 mod 同装时的崩溃已修（过滤失效占位、装备腾位加保护）；
- 服务端 mod 的物品图标也做了兜底（服务端 mod 常未注册 atlas 查询表）。

## 4. 常见问题

**Q：为什么换了电脑没有记忆？**
配置存在你本机的 `client_save` 目录里（按服务器名分文件），不跟随 Steam 账号。

**Q：同一个集群的地表和洞穴会各记一份吗？**
不会——文件按"服务器"维度命名，地表与洞穴读写同一份。只有当地表/洞穴对外名称不一致时才会分裂。

**Q：多个不同世界同名怎么办？**
会互相覆盖（文件名取自服务器名）。建议给世界起不同名字。

**Q：槽位图标还是方块？**
极少数情况：图标没注册进 atlas 查询表、且从未在本机入手过的 mod 物品（首见之前无法知道图标引用）。
入手一次后就会记住并缓存。

**Q：记忆的物品不在身上，槽位会被一直占着吗？**
看「保留已存槽位」配置：选「从不」就不占位；选「总是」会留给你；「有空位时」是折中。
