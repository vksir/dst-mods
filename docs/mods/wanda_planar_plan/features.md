# 旺达位面计划 · 功能说明

> 面向玩家的功能与用法（不含安装/部署，安装方式见工坊页面）。

「旺达位面计划」是旺达（Wanda）的加强包：重做位面伤害、让表可以命名、给旺达一个专属钟表袋，
并新增两块可以随时切换档位的**加速表**和**减速表**。所有功能都能在模组配置里单独开关。

## 1. 一眼看完

| 内容 | 一句话 |
|---|---|
| 加速表 | 右键循环：关 → 30% → 50%，移速与老化同步加快 |
| 减速表 | 右键循环：关 → 30% → 50%，敌人变慢，自己老化更快 |
| 钟表袋 | 2×8 格，只装旺达的钟表，右键开着不会自动关 |
| 位面伤害重做 | 旺达的伤害/受伤在两种伤害类型间全额转化 |
| 倒走表护盾 | 施法起手即有格挡，落地后还有 10 帧免伤 |
| 第二次机会表 | 灵魂状态用它救自己，不再损毁 |
| 命名 | 手持羽毛笔右键表，给溯源表/裂缝表起名字 |

## 2. 新增物品

三件新物品都在**钟表匠制作栏**（旺达专属）里制作。

### 2.1 加速表

- **制作**：时间碎片 ×2 + 金块 ×2 + 海象牙 ×1
- **用法**：拿在手上右键循环切换；右键文案依次是「激活」「提升档位」「停用」
- **效果**：

  | 档位 | 移动速度 | 老化速度 |
  |---|---|---|
  | 30% | ×1.30 | ×1.30 |
  | 50% | ×1.50 | ×1.50 |

- 骑乘（牛/牛鞍）时**只加快老化，不加快移速**；
- 档位记在**人物身上**：所有加速表共享同一个档位，扔掉表或塞进钟表袋，效果依然生效。

### 2.2 减速表

- **制作**：时间碎片 ×2 + 噩梦燃料 ×4 + 紫宝石 ×1
- **用法**：拿在手上右键循环切换（关 → 30% → 50%）
- **效果**：开启后周身 **12 格**内的敌对生物移动速度降低，身上带减速粒子特效；
  代价是**自己老化加速**：

  | 档位 | 敌人移速 | 自身老化 |
  |---|---|---|
  | 30% | ×0.70 | ×1.30 |
  | 50% | ×0.50 | ×1.50 |

- 只影响敌对生物（中立生物、宠物、队友不受影响）；
- 和加速表**加算叠加**：加速 50% + 减速 50% = 老化加快 **100%**（不是 125%）。

### 2.3 钟表袋

- **制作**：时间碎片 ×2 + 猪皮 ×4 + 蜘蛛丝 ×4
- **用法**：放在物品栏里，右键开启/关闭（与"添加燃料"同款的短动作）
- **特性**：
  - 2×8 格，**只放得下旺达的钟表**（其它物品放不进去）；
  - 开启后**人物走动不会关闭**，只有再右键一次才关；
  - 开启/关闭都不会连带关掉背包；开关有音效；
  - 只有旺达能打开；
  - 界面位置：游戏里选「分开」背包布局时，钟表袋面板贴在背包左侧并与之上下对齐；
    选「融合」布局时，直接占用背包那一列（两者不会同时占位）。

## 3. 已有内容的改动

### 3.1 位面伤害重做

- 旺达造成的伤害**全额按位面伤害**结算；
- 旺达受到的位面伤害**全额按普通伤害**结算。

### 3.2 倒走表护盾

- 施法**起手**就获得格挡护盾，覆盖整段前摇（不用赌时机）；
- 施放成功后追加骨头盔甲同款的 **10 帧**免伤；
- 护盾不再额外播放音效（不会出现"响两次"）。

### 3.3 第二次机会表

- 灵魂状态用第二次机会表复活自己后，表**不再损毁**。

### 3.4 给表命名

1. 把**羽毛笔**拿到鼠标上；
2. 把鼠标移到**溯源表**或**裂缝表**上，右键文案会变成「命名」；
3. 右键 → 弹出木牌式输入框 → 输入名字；
4. 名字显示为「溯源表-XXX」，所有玩家都能看到。

## 4. 模组配置

游戏内「Mods → 旺达位面计划 → 配置」可逐项开关（默认全开）：

| 配置项 | 作用 |
|---|---|
| 伤害转位面 | 旺达造成/受到的伤害按上文规则转化 |
| 位面转普通 | 同上（受伤侧） |
| 可命名 | 羽毛笔命名溯源表/裂缝表 |
| 保留复活表 | 第二次机会表复活后不损毁 |
| 倒走表护盾 | 施法起手格挡 + 10 帧免伤 |
| 加速表 | 关闭则加速表不出现/不生效 |
| 减速表 | 关闭则减速表不出现/不生效 |
| 钟表袋 | 关闭则钟表袋不出现/不生效 |

## 5. 常见问题

**Q：多块加速表能叠加吗？**
不能。档位记在人身上，所有同类表共享同一档位，避免"揣十块表速度起飞"。

**Q：把表扔了/放进钟表袋，效果还在吗？**
在。档位跟着人物走，表只是遥控器。

**Q：钟表袋会和背包冲突吗？**
不会。分开布局下两个面板左右并排（钟表袋在背包左侧，上下居中对齐）；
融合布局下钟表袋直接用背包那一列。

**Q：减速表会伤到自己人吗？**
不会。只影响带敌对标记的生物（中立生物、宠物、队友都不减速）。

**Q：加速表和减速表一起开会不会互相抵消？**
移速上是"加速自己 + 减速敌人"，互不影响；老化上是**加算**叠加，所以两者同时开老化最快。

**Q：改了档位数值，物品名会跟着变吗？**
会。物品名显示当前档位（如「加速表 50%」），与模组配置里的文案保持一致。
