# Triage Labels

各技能使用五个规范 triage 角色。本文件将这些角色映射到本仓库 issue tracker 实际使用的标签字符串（本地 markdown tracker 中，记录为 issue 文件顶部的 `Status:` 行）。

| 角色（mattpocock/skills） | 本仓库标签 | 含义 |
| ------------------------- | ---------- | ---- |
| `needs-triage`            | `needs-triage`    | 待维护者评估 |
| `needs-info`              | `needs-info`      | 等待报告者补充信息 |
| `ready-for-agent`         | `ready-for-agent` | 规格完整，可交给 AFK agent 实现 |
| `ready-for-human`         | `ready-for-human` | 需要人工实现 |
| `wontfix`                 | `wontfix`         | 不予处理 |

当技能提到某个角色（例如“打上 AFK-ready 的 triage 标签”）时，使用本表中对应的标签字符串。

如需改用其他标签词汇，直接编辑“本仓库标签”列即可。
