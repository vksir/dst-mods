# dst-mods

Dont starve together mods — 所有 mod 位于 `mods/`，每个子目录一个独立 mod。

- `mods/save_equipment_slots_fix` — Save Equipment Slots 修复版：装备槽配置跨地表/洞穴(shard)不再丢失（详见 [docs/save_equipment_slots_fix/README.md](docs/save_equipment_slots_fix/README.md)）
- `mods/arc_k9`、`mods/laser_rover_proto`、`mods/advanced_attack`、`mods/scythe`、`mods/winter_feast_clean` — 其余 mod / 原型

其他目录：`publish/`（发布配置与描述定稿）、`docs/`（开发文档与踩坑记录）、`dist/`（构建产物，gitignore）。
